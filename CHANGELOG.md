# Changelog

All notable changes to `zaffiliate` are documented here. The project uses semantic-versioning intent; unreleased work is grouped below until a production release is cut.

## Unreleased

### Added
- Canonical affiliate-commerce platform consolidating seven legacy repositories.
- Tenant isolation contracts and PostgreSQL RLS.
- TikTok and multi-channel adapter boundaries.
- Affiliate lifecycle, outreach, durable workflow, billing, AI, analytics and control-plane foundations.
- Production CI/security gates, release evidence, structured observability and metrics.
- Repository governance synchronized and adapted from `cvsz/ztemplate`.

### Security
- Fail-closed tenant boundaries, server-side provider secret handling, replay/idempotency controls, ledger invariants, secret-scanning gates and production retirement gates.

### Migration
- Legacy repositories remain preserved until migration ledger, backup/restore, secret-remediation, parity, cutover and explicit retirement gates are complete.
